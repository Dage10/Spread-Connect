## 🚀 What is Spread&Connect?

Spread&Connect is a social learning platform where users publish posts and personal presentations in knowledge areas like programming,
science, art and literature. Users can follow creators, comment, react, and chat — combining community content with real networking.

---

## ✨ Features

- 🔐 Register, login and password reset via Supabase Auth
- 👤 Profile editing — avatar, bio, password change
- 📝 Create, edit and delete posts per knowledge area
- 🎤 Create, edit and delete personal presentations
- 💬 Comments and nested replies on posts and presentations
- 👍👎 Like / dislike reactions on posts, presentations and comments
- 🏷️ Custom tags and filtering for posts
- 👥 Follow users and view their activity
- 💬 Private in-app chat between users
- 🔔 Push notifications when followed users publish new posts
- 📚 Personal activity history
- 🌐 Multi-language: Catalan, Spanish, English
- 🌓 Light / dark theme
- ☁️ Image uploads via Supabase Storage

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Language | Kotlin |
| UI | Android Fragments, View Binding, Jetpack Navigation |
| Backend | Supabase (Auth, PostgREST, Storage) |
| Push Notifications | Firebase Cloud Messaging |
| Images | Coil |
| Translation | Google ML Kit Translate |
| Async | Kotlin Coroutines |
